---
description: 離陸前点検 —— MCP接続・設定・エージェント・権限を本番前に一括確認する
---

商談やデモの**直前**に実行する点検です。目的は「問題を見つけること」なので、
「たぶん大丈夫」で通さず、**実際に叩いて**確かめてください。

> 🔒 **この出力は画面共有される可能性があります。**
> `FIGJAM_URL` の実URL、アクセスキー、個人情報を**絶対に出力しないでください**。
> 存在確認は「あり（96文字）」のように、値を伏せた形で報告すること。

以下を順に実行し、最後に一覧表で報告してください。

---

## 1. FigJam MCP の疎通（最重要）

1. 利用可能な MCP ツールの一覧に、Figma / FigJam 系のツールが**存在するか**を確認する
2. `local_env.json` から `FIGJAM_URL` を読む（**値は出力しない**）
3. **実際にその URL を取得してみる。** 到達できたら、取得できた要素の件数だけを報告する
4. 失敗したら、原因を次のどれかに分類する
   - `未接続` … MCP ツール自体が一覧に無い
   - `認証` … 認証・ログインが必要
   - `権限` … URL には到達したがアクセスを拒否された
   - `URL不正` … URL の形式や参照先が誤っている
   - `タイムアウト` … 応答が返らない

**ここが ❌ でも本番は回せます。** `/draft` は引数による直接入力にフォールバックできるためです。
その場合は「FigJam は使わず `/draft <メモ>` または `/draft @inputs/xxx.md` で回す」と明示してください。

## 2. 設定パラメータ

`local_env.json` に以下が揃っているか。**値は伏せ、有無と文字数だけ**報告する。

- `PROJECT_NAME` / `OUTPUT_DIR` / `PROJECT_SUMMARY` / `FIGJAM_URL` / `RAW_HEARING_MEMO`
- **`OUTPUT_DIR` が無い場合は ❌。** 出力先が決まらず `/draft` が走れません

## 3. エージェントと knowledge

- `.claude/agents/` に3体（`product-agent` / `design-agent` / `quality-agent`）が存在するか
- `.claude/knowledge/` に必要なファイルが揃っているか（`shared` 2件 / `product-agent` 3件 / `design-agent` 3件 / `quality-agent` 2件）
- 各エージェントの `Knowledge Loading` に列挙されたパスが、**実在するか**（リンク切れの検出）

## 4. 出力先の衝突

- `OUTPUT_DIR` が指すディレクトリが**既に存在しないか**を確認する
- 存在する場合は ⚠️。上書きすると前回の成果物が失われます。
  スラッグを変えるか、既存を退避するかを人間に確認してください

## 5. 権限（止まらずに走れるか）

`.claude/settings.local.json` の `permissions.allow` を確認し、
`/draft` が必要とする以下が**事前許可されているか**を判定する。

- ファイル読み取り（Read / Glob / Grep）
- ファイル書き込み（Write / Edit）
- サブエージェントへの委譲（Task）
- Figma / FigJam の MCP ツール

**未許可があれば ⚠️ とし、こう伝えてください：**
「本番前にリハーサルで `/draft` を1回通し、権限プロンプトで毎回『常に許可』を選んでください。
手で JSON を書くと記法を誤り、本番で再度確認が出ます」

---

## 報告フォーマット

> ⚠️ **表組み（Markdown テーブル）を使わないこと。** ターミナルで折り返して判読不能になります。
> **1行は全角40文字／半角80文字以内**に収め、長い値は要約してください。
> 画面共有される前提で、狭い幅でも崩れない形にすること。

以下の形式で、**1項目1行**で出力してください。

```
1. FigJam MCP 疎通       ✅  要素56件を取得
2. 設定パラメータ         ❌  OUTPUT_DIR なし
3. エージェント/knowledge  ✅  3体・10ファイル・リンク切れなし
4. 出力先の衝突           ✅  なし
5. 権限                  ⚠️  Read/Write/Task が未許可
```

判定の付け方：

- 項目4は、衝突が**なければ ✅**（`—` にしない）
- ツール名やパスが長い場合は末尾だけを示す（例: `...get_figjam`）
- ❌ と ⚠️ の**詳細は、一覧の下に改めて箇条書き**で書く。一覧の行内に詰め込まない

一覧のあとに区切り線を引き、**「本番可否」を1〜2行**で述べてください。

- ❌ が `OUTPUT_DIR` またはエージェント欠落 → **走れません。先に直してください**
- ❌ が FigJam MCP のみ → **走れます。引数入力に切り替えてください**
- ⚠️ のみ → **走れますが、途中で止まる可能性があります**
