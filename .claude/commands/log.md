**最速で終わらせること。** これは商談中、お客様の目の前で叩くコマンドである。
knowledge の読み込み、サブエージェントへの委譲、確認の問い返しは**すべて禁止**。
`review_history.md` への追記だけを行い、1〜2行で完了報告する。

## 引数の解釈

```
/log <お客様の言葉> → <写像先>
/log <お客様の言葉>
```

- `→`（または `->` `/`）があれば、前を**お客様の言葉**、後ろを**写像先**とする
- 区切りが無ければ全体を「お客様の言葉」とし、写像先は空欄（`—`）にする
- お客様の言葉は**言い換えず、聞こえたまま**記録する。要約すると後で文脈が失われる

$ARGUMENTS

## 手順

1. `local_env.json` の `OUTPUT_DIR` を読み、`<OUTPUT_DIR>/review_history.md` を対象とする
2. `## 顧客反復ログ` セクションを探す。**無ければ見出しと表ヘッダごと作成**する

```markdown
## 顧客反復ログ

| # | 時刻 | お客様の言葉 | 写像先 | 所要 | 上流への反映 |
|---|---|---|---|---|---|
```

3. 既存の最終行を見て、次の連番と**前行の時刻**を取得する
4. 現在時刻を `date +%H:%M:%S` で取得する
5. **所要 = 現在時刻 − 前行の時刻**（分秒表記）。最初の1件目は `—`
6. 1行追記する。`上流への反映` は空欄（`—`）にしておき、DEVELOP パスで埋める

## 出力

追記した1行をそのまま表示し、それ以上は何も書かない。

```
✅ #2  14:34:12  「押しにくい」 → W/D  （前行から 2分10秒）
```

## 注意

- **写像先は `Guidelines.md` の「変更要求 → トークン写像表」の用語に合わせる。**
  表に無い要求なら、写像先に `新規` と書き、DEVELOP パスで写像表へ追記する
- 追記のみ。**過去の行を書き換えてはならない**
- このログは「速さ」を裏づける唯一の証跡である。仕様書に速度は残らない
