# Guidelines.md — デザインシステム規約（ITERATE）

## 1. 禁則事項（P-1〜P-6）

可読性はこれらの禁則に常に優先する。両者が衝突した場合は可読性を採る（`aesthetic-guardrails.md` §0）。
本節は `figma_make_prompt.md` の Constraints 節と同一内容を正本として保持する。

| # | 禁止対象 | 禁止する理由 |
|---|---|---|
| P-1 | 意味を持たない装飾グラデーション背景（紫→青、ピンク→オレンジ等の全面グラデーション、根拠なきグロー、既定値のグラスモーフィズム） | 情報の階層を伝えず、面を濁らせるだけの装飾。奥行きは影ではなく構造と余白で表現する |
| P-2 | Inter / Arial / Helvetica（既定値としての）/ Roboto / system-ui の無思考な採用 | 選定ではなく「選定の放棄」。本案件では §3 の書体を実体名で使う |
| P-3 | 角丸・影・境界線の一括適用（すべてのカードが同じ角丸＋同じドロップシャドウ） | 階層が消え、全要素が等価に見える。強調は「全部を目立たせない」ことでしか生まれない |
| P-4 | 絵文字によるアイコン代替、多色イラストの安易な配置 | 解像度・文化依存・トーンの破壊。状態バッジ（未着手／対応中／完了）は色ではなく文字ラベルで弁別する（OQ-1 未確定のため色単独に依存しない） |
| P-5 | 意味なく中央揃えされた長文、全要素の等間隔配置 | リズムの欠如。視線の起点が消失する |
| P-6 | 彩度の高い色の広面積使用 | `--accent` / `--accent-alert` は面積比で数％以内に限定する（下記§2） |

本案件で特に注意すべき点: 深夜3時台の判断は疲労下で行われる（M-12）。禁則を守った結果として
主要導線が「見つからない」状態になった場合は、`aesthetic-guardrails.md` §0 に従いコントラストか
サイズを引き上げて発見可能性を確保する（面積は増やさない）。

| トークン | 値 | 対比相手 | 比率 | 要求 |
|---|---|---|---|---|
| `--bg` | `#17181C` | — | — | — |
| `--fg` | `#ECEAE6` | `--bg` | 14.76:1 | 7.0:1（OQ-1: 視力特性不明のため AA 4.5:1 から引き上げ） |

## 3. タイポグラフィ

書体スタック: `"BIZ UDPGothic", "Yu Gothic UI", sans-serif`
選定理由: OQ-1（視力特性不明）と深夜の疲労による判読精度低下を前提に、UD（ユニバーサルデザイン）書体が0/Oや1/lの誤読を構造的に防ぐよう設計されているため採用する。

| トークン | サイズ | 用途 |
|---|---|---|
| `--font-size-heading` | 20px | 第1階層（工程状況一覧／判断根拠入力欄／未完了・要フォロー事項一覧） |
| `--font-size-body` | 16px | 本文・ボタンラベル |
| `--font-size-caption` | 14px | タイムスタンプ・副次ラベル |

## 4. スペーシング（近接／2値必須）

| トークン | 値 | 用途 |
|---|---|---|
| `--space-inner`（群内） | 8px | 同一項目内の要素間隔（ラベルと値など） |
| `--space-outer`（群間） | 24px | 群と群の間隔（工程カード間・セクション間）。群内の3倍を確保 |

## 5. コンポーネント規約（D-02 由来: W拡大・下端固定）

| トークン | 寸法 | 用途 |
|---|---|---|
| `--target-primary` | 高さ 56px／最小幅 220px／`flex-shrink: 0` | 主要導線（記録を確定する／状態を更新する／引き継ぎを確定する）。最長ラベル「引き継ぎを確定する」から逆算 |
| `--target-choice` | 高さ 44px／最小幅 184px／`flex-shrink: 0` | 工程選択・状態選択（未着手／対応中／完了）。最長ラベル「アラート初動確認」から逆算 |

主要導線は画面下端に固定配置する（D-02）。

## 6. モーション規約

`aesthetic-guardrails.md` §2⑥「モーションは意味の伝達手段に限る」に従い、装飾目的の常時アニメーションは禁止する。
以下は「状態変化の因果を伝える」「注意を誘導する」の2用途に限定した最小セットである。

| トークン | 値 | 用途 | 導出根拠 |
|---|---|---|---|
| `--motion-duration-state` | 150ms | 状態バッジ（未着手／対応中／完了）の切替、記録確定時のフィードバック | C-2 の並行/割り込み運用では素早い因果確認が必要。深夜の眠気（M-12）下でも遅延と感じない下限として短時間に設定 |
| `--motion-duration-alert-enter` | 200ms | 報告義務アラート（T-10）の初出表示（フェード＋わずかな位置変化） | 静寂な環境（M-15）での唐突な出現を避けつつ、見逃し防止（M-19）のため十分に知覚できる速度 |
| `--motion-easing` | `ease-out` | 上記2トークン共通のイージング | 減速で終わることで、動きの終端が視線の停止点として機能する（減光環境での過剰な残像を避ける） |

**禁止事項**
- 報告義務アラートの**継続的な点滅・明滅は禁止**する。単発の入場アニメーション（`--motion-duration-alert-enter`）の後は静止した強調表示（`--accent-alert`＋文字ラベル）を保持する。理由は二つ ―― (1) 静寂な環境（M-15）で反復的な動きは注意散漫の要因になる、(2) WCAG 2.3.1（点滅コンテンツ）への抵触を避ける
- `--bg` を基調とする Dark 極性（D-01）のもとでは、明滅・急激な明度変化を伴うモーションを禁止する。暗順応（M-18）を崩すため
- 装飾目的（プロダクトの「賑やかさ」演出等）のホバーエフェクト・常時ループアニメーションは使用しない

**`prefers-reduced-motion` 対応**: 上記いずれのモーションも、OS 設定が reduce を要求している場合は
位置変化を廃し、`opacity` の即時切替（duration 0ms 相当）に置き換える。深夜の当直という業務用途で
モーション設定に配慮できないことは、それ自体が過酷な利用環境における可読性の欠陥となる（§0 の優先順位）。

## 7. 変更要求 → トークン写像表

| お客様の言葉 | 変換先 | 操作 |
|---|---|---|
| 「もっと明るく」 | `--bg` | 明度を1段上げる（極性は変えない） |
| 「押しにくい」 | `--target-primary` / `--target-choice` | 最小幅・高さを上げる |
| 「ごちゃごちゃする」 | `--space-outer` | 群間の余白を1段広げる |
| 「地味」「華やかに」 | `--accent` / `--accent-alert` | 面積を増やさず、彩度かコントラストで解く |
| 「アラートが目立たない」 | `--accent-alert` | コントラストを引き上げる（面積は増やさない） |

## 8. 禁止識別子リスト（DOM バインド規約）

`frontend-security.md` 準拠。実装コードを生成する場合、以下を全面禁止とする（例外なし）。

- `innerHTML` / `outerHTML` / `insertAdjacentHTML` / `document.write` による
  ユーザー入力・外部応答・AI生成テキストの展開
- 動的要素は `document.createElement()` で生成し、テキストは `.textContent`（または `.innerText`）経由でのみバインドする
- URL を解釈する属性（`href` / `src` / `formaction`）は `setAttribute()` で設定し、
  `javascript:` / `data:` スキームを拒否する検証を必須とする
- イベントは `addEventListener` のみで束縛する。インライン `onclick=`、`eval()`、`new Function()`、
  文字列引数の `setTimeout` を禁止する
- テンプレートリテラルによる HTML 文字列組み立てを禁止する
- フレームワークのエスケープ回避 API（`dangerouslySetInnerHTML`、`v-html`、`@html` 等）も同様に禁止する

**禁止識別子（grep で検知する）**
```
innerHTML
outerHTML
insertAdjacentHTML
document.write
eval(
new Function(
dangerouslySetInnerHTML
v-html
```

検査コマンド: `python3 scripts/check_forbidden.py examples/night-app/`（終了コード0で PASS）。
本案件で特にリスクとなるのは、判断根拠入力欄（S02）と対応記録一覧（S03）――当直担当者が入力した
自由記述テキストを画面へ描画する箇所である。ここが本規約の主要な適用対象であり、`textContent` 経由の
バインドを徹底する。
