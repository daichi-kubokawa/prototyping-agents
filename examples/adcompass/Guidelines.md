# Guidelines.md — デザインシステム規約（DRAFT）

> 禁則事項 P-1〜P-6 と禁止識別子リストは `figma_make_prompt.md` の Constraints 節に転記済み。
> ここでは各具体値の由来のみを一行で記す。すべての値は design.md D-01（Light）と
> requirements.md C-1〜C-5（業務ツール・長文読解・信頼感）から導出した計算結果である。

## 2. カラートークン（コントラスト比 実測値）

D-01「Light 採用」に基づく。ダークサイドの加点要因（暗順応・光害回避）が無いため、Light 側のみ設計する。

| トークン | 値 | 役割 | コントラスト比（対 `--color-bg`） |
|---|---|---|---|
| `--color-bg` | `#F6F7F9` | 背景。純白ではなく淡い寒色グレーとし、長文読解時の眩しさを抑制 | — |
| `--color-fg-primary` | `#1B1F24` | 本文・見出し文字 | 15.4:1（AAA 到達） |
| `--color-fg-secondary` | `#5B6472` | 補助ラベル・キャプション | 5.6:1（AA 到達） |
| `--color-border` | `#7C8592` | 罫線・カード境界 | 3.5:1（WCAG 1.4.11 非テキスト下限クリア） |
| `--color-accent` | `#2C5AA0` | 主要導線・確認待ちバッジ（面積比は §5 参照） | 6.4:1 |

- 背景を純白にしなかった理由: 業務ツールを長時間参照する用途で、純白大面積は眩しさの原因になる
  （aesthetic-guardrails.md「Light 採用時の追加義務」）
- アクセントに赤系ではなく深い青系を選んだ理由: フィードバックは評価に近い性質を持つため
  （requirements.md C-5）、警告色的な赤は威圧的に映るリスクがあり、信頼感を損なわない寒色を採用した

## 3. タイポグラフィ

| トークン | 値 |
|---|---|
| `--font-heading` | `"Zen Kaku Gothic New", sans-serif` |
| `--font-body` | `"BIZ UDPGothic", sans-serif` |
| `--font-size-heading` | 24px |
| `--font-size-body` | 16px |
| `--font-size-caption` | 13px |

選定理由（1文）: 本文は判断基準・フィードバックという長文を読ませる用途のため、
0/O・1/l の判別性が高いユニバーサルデザイン書体 BIZ UDPGothic を採用し、
見出しは Zen Kaku Gothic New の太字ウェイトでコントラストを作り階層を明確にした
（Inter/Arial/Roboto 等の既定値は P-2 により不採用）。

## 4. スペーシングとレイアウトグリッド

- ベース単位: 8px
- カード内余白: 16px（2単位）
- セクション間余白: 24px（3単位）
- 左サイドナビ幅: 240px（D-02 の固定ナビゲーションに対応）

## 5. コンポーネント規約（主要導線のターゲット寸法）

- 主要導線（工程ステッパー項目・案件カード）の最小高さ: 36px。
  入力方式がマウス（高精度ポインタ）であるため、タッチ規準の44px下限は適用せず、
  デスクトップ向けデザインシステムの快適密度規準を採用した（D-02 参照）
- アクセント（`--color-accent`）の使用面積は画面全体の数%以内に限定し、
  確認待ちバッジ・主要ボタン・現在地インジケータの「点」にのみ用いる

## 7. 変更要求 → トークン写像表

| お客様の言葉 | 変換先 | 操作 |
|---|---|---|
| 「もっと明るく」 | `--color-bg` | 明度を1段上げる（極性は Light のまま変えない） |
| 「文字が小さい／読みにくい」 | `--font-size-body` | サイズを1段上げる、または `--color-fg-secondary` の使用箇所を `--color-fg-primary` に格上げ |
| 「押しにくい」 | コンポーネント規約の最小高さ | 36px を1段引き上げる |
| 「ごちゃごちゃする」 | スペーシング | セクション間余白を1段上げる |
| 「地味」「もっと目立たせて」 | `--color-accent` | ❌ 面積を増やさない。コントラストを上げるか、対象を厳選する |
| 「威圧的／きつい印象」 | `--color-accent` | 彩度・明度を1段下げる（青系の極性は変えない） |
