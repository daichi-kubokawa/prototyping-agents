# figma_make_prompt.md — Figma Make 連携プロンプト（DRAFT）

以下をそのまま Figma Make に貼り付けてください。

---

## Task
設備保全の現場作業員が、屋外プラントで点検結果をその場で記録するためのモバイル向けプロトタイプ
画面（点検記録フォーム）を作成する。

## Context
- 利用者: 設備保全の現場作業員（熟練度に幅あり、年配作業員も含む）
- 状況: 計測器を片手に持ち、革手袋を着けたまま、屋外プラントで1点検箇所2〜3分の巡回記録を行う。
  晴天時は直射日光で画面が読めず、雨天・冬季16時以降は薄暗い時間帯もある。周辺は騒音大。
- 記録は元請け提出報告書の根拠となり、誤り・書き漏れは契約上・信頼上の問題に直結する。
- 参照設計判断: D-01（輝度極性）= Light 採用。D-02（操作アンカー）= 下端アンカー固定、
  主要導線は画面下部の片手親指可動域に配置。

## Elements
- 背景 `--color-bg: #FFFFFF`、主要テキスト `--color-fg-primary: #1A1A1A`
  （対背景コントラスト約17.4:1）、補助テキスト `--color-fg-secondary: #595959`（約7.0:1）、
  境界線 `--color-border: #D0D0D0`（極細罫線、面塗りは行わない）、
  アクセント `--color-accent: #0058CC`（画面全体の面積比で数％以内、記録確定ボタン等1点のみ）
- 書体: 欧文/数字 `"Atkinson Hyperlegible"`、和文 `"BIZ UDPGothic"`、フォールバック `sans-serif`
- サイズ3段階: 見出し `24px` / 本文・記録数値 `20px` / 補助 `16px`
- スペーシングスケール（8pxベース）: `4 / 8 / 16 / 24 / 32`。密度は疎。
- 主要導線（記録確定・次項目送り）ボタンは画面下端固定、最小タップ領域 `64×64px`
- 破壊的操作（削除・リセット等）は画面上部に配置するか、確認ステップを挟む

## Behavior
- 主要導線（記録確定）は片手親指の可動域である画面下部に固定し、常に同じ位置・同じ寸法で表示する
- 破壊的操作は誤爆防止のため、到達距離を意図的に離すか、確認ダイアログを挟む
- スクロールするコンテンツと下端固定ボタンが競合する場合、固定ボタンが本文を隠さないよう
  セーフエリアを確保する
- 装飾目的の常時アニメーションは追加しない

## Constraints

### 禁則事項（P-1〜P-6、必ず遵守）
- P-1: 意味を持たない装飾グラデーション背景・根拠なきグロー・既定値のままのグラスモーフィズムを
  使用しない。奥行きは構造と余白で表現する
- P-2: Inter / Arial / Helvetica（既定値としての）/ Roboto / system-ui を無思考に採用しない。
  本プロンプト指定の書体を使用する
- P-3: 角丸・影・境界線をすべての要素に一括適用しない。強調は「全部を目立たせない」ことで作る
- P-4: 絵文字によるアイコン代替、多色イラストの安易な配置を行わない
- P-5: 意味なく中央揃えされた長文、全要素の等間隔配置を避ける
- P-6: 彩度の高い色を広面積で使用しない。アクセントは点（数%以内）に限定する

### DOM バインド規約（例外なき禁止）
- `innerHTML` / `outerHTML` / `insertAdjacentHTML` / `document.write` によるユーザー入力・外部応答・
  AI生成テキストの展開を全面禁止する
- 動的要素は `document.createElement()` で生成し、テキストは `.textContent` 経由でのみバインドする
- URLを解釈する属性（`href` / `src` / `formaction`）は `setAttribute()` で設定し、`javascript:` /
  `data:` スキームを拒否する
- イベントハンドラは `addEventListener` のみ。インライン `onclick=`、`eval()`、`new Function()`、
  文字列引数の `setTimeout` を禁止する
- テンプレートリテラルによる HTML 文字列組み立てを禁止する
- フレームワーク採用時のエスケープ回避API（`dangerouslySetInnerHTML`、`v-html` 等）も禁止する

### 禁止識別子リスト（grep で機械的に検知）
```
innerHTML
outerHTML
insertAdjacentHTML
document.write
eval(
new Function(
dangerouslySetInnerHTML
v-html
```

### その他
- ビルド工程なしで単一 HTML として開けること
- 機密情報（実URL・アクセスキー等）を出力に含めないこと
