## Task

「RESONOTE（レゾノート）」―― 日常の小さな心の動きを、写真1枚・短文・感情タグで静かに記録し、
閉じた関係の中で評価ではなく共鳴し合う SNS のモバイルプロトタイプを、以下9画面分生成すること。

## Context

- ターゲットユーザー：SNS に習熟した20代後半、感受性が高く風景の“空気”を感じ取りやすい層
- 利用シーン：散歩・通勤中の屋外、日中〜夕方の自然光下が中心（Assumption）。片手操作が主と推測される
- トーン：静けさ・透明感・呼吸感。評価文化（いいね数の誇示等）を明確に避ける
- 技術構成：単一 HTML／CSS／Vanilla JS を想定したプロトタイプ（フレームワーク不使用）

## どのファイルを読むか

1. `screens.md` ―― 画面構成（S00〜S08）・遷移・表示要素・空状態と条件分岐
2. `content.md` ―― 画面に表示する実際の文言（仮説として明記されたもの）
3. `Guidelines.md` ―― カラートークン・タイポグラフィ・スペーシング・コンポーネント寸法
4. `design.md` ―― D-01（Light 採用）・D-02（下端アンカー）の根拠（なぜこの配色・配置なのか）
5. `requirements.md` ―― Must Have の受入基準、非機能要件、Open Questions

## どの情報を優先するか

- `screens.md` の「表示要素」と「アクション」を最優先で UI コンポーネント化すること
- 本文テキストは推測で生成せず、**必ず `content.md` の記載をそのまま使用**すること
- ボタンの表示/非表示・遷移の分岐は `screens.md` の「表示の分岐」に従うこと（空状態を含む）
- `content.md` に「仮説」「要確認」と明記された文言も、**現時点ではそのまま採用**すること
  （検証は次回商談以降で行う。プロトタイプ段階でダミー文に置き換える必要はない）

> ⚠️ **画面に表示する本文テキストは、推測で生成せず、必ず `content.md` の記載内容をそのまま使用すること。
> ダミーテキスト・プレースホルダーでの生成を禁止する。**

## Behavior（`screens.md` の「表示の分岐」より抜粋・転記）

- S02（オンボーディング）: 1〜4ページ目は「スキップ」のみ、5ページ目のみ「はじめる」に切替
- S04（パーソナライズ）: 写真未選択のままスキップ可能。未選択の場合は S06 で一般文言にフォールバック
- S07（投稿一覧）: 投稿0件の初回は、欠落訴求を避けた穏やかな空状態文言を表示（`content.md` 参照）
- S08（投稿作成）: 写真未選択で CTA 無効化、100文字超過で送信無効化、投稿完了後は D 最小の取り消し導線を提示

## Constraints

### 審美規約（禁則事項 P-1〜P-6・全面遵守）

| # | 禁止対象 |
|---|---|
| P-1 | 意味を持たない装飾グラデーション背景（根拠なきグロー、既定値のグラスモーフィズムを含む） |
| P-2 | Inter / Arial / Helvetica（既定値としての）/ Roboto / system-ui の無思考な採用（本件は `Guidelines.md` 指定の M PLUS 1 を使用） |
| P-3 | 角丸・影・境界線の一括適用（すべてのカードへ同一の角丸＋同一のドロップシャドウ） |
| P-4 | 絵文字によるアイコン代替、および多色イラストの安易な配置 |
| P-5 | 意味なく中央揃えされた長文、および全要素の等間隔配置 |
| P-6 | 彩度の高い色の広面積使用（`--color-accent` は面積比数％以内の「点」用途に限定。`Guidelines.md` §1 参照） |

面ではなく線と点で階層を作ること。背景は単一の静かな面に留め、アクセントは装飾ではなく
「今、注意を向けるべき唯一の場所」を指す機能として使うこと。

### DOM バインド規約（フロントエンド防衛・例外なき禁止）

- `innerHTML` / `outerHTML` / `insertAdjacentHTML` / `document.write` による
  テキスト・HTML の動的展開を**全面的に禁止**する
- すべての動的要素は `document.createElement()` で生成し、テキストは `.textContent` 経由でのみバインドする
- 属性値の設定は `setAttribute()` を用い、URL を解釈する属性（`href` / `src` 等）には
  `javascript:` / `data:` スキームを拒否すること
- イベントハンドラは `addEventListener` でのみ束縛する。`onclick=` 等のインライン属性、`eval()`、
  `new Function()`、文字列引数の `setTimeout` を禁止する
- テンプレートリテラルによる HTML 文字列組み立てを禁止する（静的に見えても禁止）

**禁止識別子リスト（grep 検知用）**:
```
innerHTML
outerHTML
insertAdjacentHTML
document.write
eval(
new Function(
dangerouslySetInnerHTML
v-html
```

### その他

- プロンプト本文・生成物のラベル文言は日本語で統一すること
- `--color-accent`（`#A2D32A`）を文字色として単体使用しないこと（背景比コントラスト不足。
  `Guidelines.md` §1 の用法制限に従うこと）
- 主要 CTA は画面下端・セーフエリア直上に固定し、高さ 52px 以上を確保すること（D-02 準拠）
