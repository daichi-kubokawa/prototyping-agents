# ParentSync — 案件固有ルール

リポジトリ共通ルールは [`/CLAUDE.md`](../../CLAUDE.md) を参照。本ファイルは **ParentSync 案件に限定**した制約を定義する。

---

## 1. 案件概要

深夜の授乳・オムツ替えを行う育児当事者が、自然言語のワンライン入力で
「育児ログ」と「買い物 ToDo」へ同時に仕分けできる、単一 `index.html` 完結のプロトタイプ。

---

| C-2 | タスク | 1回あたり数秒〜十数秒の短時間入力。連続注視時間は極めて短い。記録漏れは翌日に響く |

## 4. 案件固有のセキュリティ要件

- **APIキーの永続化を禁止する。** セッション終了時（タブ／ブラウザを閉じたとき）に自動破棄されること。
  不揮発性ストレージへの保存は、漏洩リスクのため厳禁とする
- **フェイルセーフ・フォールバック**: APIキー未設定時、または API 接続エラー・タイムアウト発生時は、
  未処理例外を投げて画面をフリーズさせず、ブラウザ側のローカル分類処理へ即座に縮退（Graceful Degradation）すること
- 上記の実装方式（保持先の選定、タイムアウト制御の手段）は `design.md` で導出する
